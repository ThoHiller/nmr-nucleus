applyRegularization

PURPOSE

applies regularization procedures from the

SYNOPSIS

function [Kreg,lambda] = applyRegularization(K,g,L,lambda_in,flag,order,noise_level)

DESCRIPTION 

applyRegularization applies regularization procedures from the
Regularization toolbox from P. Hansen -- for all methods (except "manual")
the regularization parameter lambda is determined by different criteria
and using a SVD

 Syntax:
       applyRegularization(K,g,L,lambda_in,flag,order,noise_level)

 Inputs:
       K - Kernel matrix
       g - signal
       L - smoothness constraint matrix
       lambda_in - regularization parameter
       flag - flag for regularization method:
              'manual', 'gcv_tikh', 'gcv_trunc', 'gcv_damp', 'discrep',
       order - smoothness constraint: '0', '1' or '2'
       noise_level - noise level for 'discrep' method (discrepancy principle)

 Outputs:
       Kreg - expanded (regularized) Kernel matrix; the number of extra
              rows is NOT always size(L,1) (truncated/damped SVD/GSVD),
              extend the data vector by size(Kreg,1)-length(g) zeros
       lambda - determined lambda (for 'gcv_trunc': the truncation index
                k, i.e. the number of retained singular values)

 Example:
       [Kr,lam] = applyRegularization(K,s,L,lambda_in,flag,Lorder,noise)

 Other m-files required:
       Regularization Toolbox
       csvd
       cgsvd
       gcv
       discrep

 Subfunctions:
       getGCVparameter
       getTruncatedSystem
       getDampedSystem
       getGSVDComponents
       restoreCurrentFigure

 MAT-files required:
       none

0154 function Kreg = getTruncatedSystem(K,L,order,k)
0155 % Returns Kreg = [K_k; w*P_d] such that the unconstrained least-squares
0156 % solution of Kreg*f = [g; 0] is exactly the truncated SVD (order 0) or
0157 % truncated GSVD (order > 0) solution:
0158 %   - K_k contains only the k retained (generalized) singular components
0159 %     (plus, for the GSVD, the unregularized null space of L)
0160 %   - P_d projects onto the discarded components, which are thereby
0161 %     forced to zero (any w > 0 gives the TSVD/TGSVD solution)
0162 % The weight w is the smallest retained (generalized) singular value, so
0163 % that with the non-negativity constraint of LSQNONNEG/LSQLIN discarded
0164 % components are penalized at the truncation level.
0165 % NOTE: the calling routine has to extend the data vector by
0166 % size(Kreg,1)-length(g) zeros.
0167 [m,n] = size(K);
0168 if order == 0
0169     [U,S,V] = svd(full(K),'econ');
0170     s = diag(S);
0171     k = max(1,min(k,numel(s)));
0172     if m < n
0173         % complete the basis with the null space of K
0174         V = [V null(V')];
0175     end
0176     Kk = U(:,1:k)*diag(s(1:k))*V(:,1:k)';
0177     Kreg = [Kk; s(k)*V(:,k+1:n)'];
0178 else
0179     [X,Xinv,sigma,mu,nNull] = getGSVDComponents(K,L);
0180     % gamma = sigma/mu; the null space of L (mu = 0) has gamma = Inf and
0181     % is always retained (like tgsvd.m of the Regularization Tools)
0182     gamma = sigma./mu;
0183     [~,ord] = sort(gamma,'descend');
0184     nKeep = max(nNull+1,min(n,nNull+k));
0185     keep = ord(1:nKeep);
0186     disc = ord(nKeep+1:end);
0187     Kk = K*X(:,keep)*Xinv(keep,:);
0188     w = sigma(keep(end));
0189     Kreg = [Kk; w*Xinv(disc,:)];
0190 end
0191 
0192 return

0194 %%  subfunction: damped SVD / GSVD as an augmented LSQ system
0195 function Kreg = getDampedSystem(K,L,order,lambda)
0196 % The damped SVD solution f = sum_i s_i/(s_i+lambda) * (u_i'g/s_i) * v_i
0197 % is the minimizer of
0198 %   ||K*f - g||^2 + lambda*||diag(sqrt(s))*V'*f||^2
0199 % i.e. of [K; sqrt(lambda)*diag(sqrt(s))*V']*f = [g; 0].
0200 % For the damped GSVD (filter gamma/(gamma+lambda), gamma = sigma/mu)
0201 % the penalty is lambda*sum_i sigma_i*mu_i*y_i^2 with y = inv(X)*f.
0202 % NOTE: the calling routine has to extend the data vector by
0203 % size(Kreg,1)-length(g) zeros.
0204 [m,n] = size(K);
0205 if order == 0
0206     [~,S,V] = svd(full(K),'econ');
0207     s = diag(S);
0208     P = diag(sqrt(lambda*s))*V';
0209     if m < n
0210         % null space of K: zero component (minimum-norm DSVD solution)
0211         P = [P; sqrt(lambda*s(end))*null(V')'];
0212     end
0213     Kreg = [K; P];
0214 else
0215     [~,Xinv,sigma,mu] = getGSVDComponents(K,L);
0216     Kreg = [K; diag(sqrt(lambda*sigma.*mu))*Xinv];
0217 end
0218 
0219 return
